# 차근차근 카페 레시피 (Recipe Guide)

**차근차근 카페 레시피**는 성인 발달장애인이 혼자서 다양한 카페 음료(예: 아메리카노(에어로프레스))를 스스로 만들 수 있도록 돕기 위해 개발된 **반응형 시각적 작업 지원 웹 애플리케이션**입니다. 

기존 진행 중인 "배달왔삼" 웹앱의 브랜드 톤앤매너(Teal 청록 테마)와 캐릭터 에셋(달곰이)을 적용하여 친근한 인터페이스를 완성했습니다. 다른 프로젝트에도 쉽게 모듈(플러그인) 형태로 삽입될 수 있도록 범용적으로 설계되었습니다.

## ✨ 주요 기능 (Features)
- **모듈화 및 독립성**: 빌드 도구나 무거운 프레임워크 없이 **순수 HTML, CSS, Vanilla JS**로만 작성되어 어디든 쉽게 이식 가능합니다.
- **모바일 우선(Mobile-First) 반응형 디자인**: 스마트폰, 태블릿, 데스크탑 등 어떤 환경에서도 명확하고 큼직한 UI를 제공합니다.
- **인지적 접근성 최적화**:
  - 한 화면에 하나의 지시사항만 배치하여 인지적 부담 최소화
  - 제목(맥락 제공) ➡️ 이미지 ➡️ 지시문 순서로 레이아웃을 배치하여 시선 흐름을 최적화
  - "저어주기"와 "기다리기" 등 서로 다른 행동을 명확히 단계별로 분리
  - 캡 ➡️ *검정 뚜껑*, 플런저 ➡️ *눌러내리는 막대* 등 묘사 중심의 쉬운 한글을 채택
- **기본 음성 안내 (TTS 기본 탑재)**: 
  - 앱 진입 시 음성 안내 기능이 기본값(`ON`)으로 활성화되어, 단계를 넘어갈 때마다 지시사항을 친절한 목소리로 자동 재생합니다.
- **안전장치가 포함된 모달 타이머**: 
  - 타이머 작동 단계에 도달하면 화면 중앙에 즉시 카운트다운 모달이 열려 자동으로 시간이 흐릅니다. 
  - 타이머 카운트다운 중에는 ✕(닫기) 버튼이 화면에 표시되지 않아 오작동을 방지하며, 일시정지 또는 0초 완료 시에만 다시 노출되어 안전하게 조작할 수 있습니다.

## 📂 프로젝트 구조 (Directory Structure)

```text
/
├── recipe-guide/
│   ├── index.html            # 진입점 및 기본 레이아웃
│   ├── handoff.md            # 인지적 접근성 설계 요소 및 유지보수용 개발 핸드오프 문서
│   ├── css/
│   │   └── recipe-guide.css  # 독립적으로 네임스페이스(#recipe-guide-app)가 적용된 틸 테마 스타일
│   ├── js/
│   │   ├── recipe-data.js    # 레시피 데이터 (단계, 순화어 지시문, 음성 대본 등)
│   │   └── recipe-guide.js   # 앱의 핵심 비즈니스 로직, 타이머, TTS 제어 및 UI 렌더링
│   ├── assets/
│   │   ├── aeropress/        # 아메리카노(에어로프레스) 단계별 최적화 JPG 이미지들 (가로 800px)
│   │   └── baedalwatsam/     # 배달왔삼 공식 브랜딩 자산 (로고 및 달곰이 캐릭터 에셋)
│   └── walkthrough/
│       └── walkthrough.md    # 최근 사용성 및 UX 개선 사항 히스토리
└── README.md
```

## 🚀 사용 및 배포 방법 (How to Run)

1. **로컬 환경 실행**: 별도의 백엔드나 서버 설치 없이 `recipe-guide/index.html` 파일을 웹 브라우저에서 바로 실행할 수 있습니다.
2. **웹 배포**: 정적 파일(HTML, CSS, JS)로만 이루어져 있으므로 **GitHub Pages**, Vercel, Netlify 등에 폴더를 올리는 것만으로 즉시 무료 배포가 가능합니다.
3. **기존 앱(배달왔삼)에 통합하기**: 
   - `css/recipe-guide.css`와 `js/` 안의 파일들을 기존 앱으로 복사합니다.
   - 기존 앱의 HTML에 `<div id="recipe-guide-app"></div>` 컨테이너를 생성합니다.
   - 스크립트(`recipe-guide.js`)를 모듈로 불러오면 해당 `div` 내부에 레시피 가이드가 자동으로 렌더링됩니다.

## 🛠 확장 방법 (Adding New Recipes)

새로운 음료(예: 바닐라라떼, 콤부차, 말차 바닐라라떼)를 추가하려면 `js/recipe-data.js` 파일에 새로운 레시피 객체를 추가하고, 해당 레시피의 `comingSoon: false`로 설정하면 홈 화면에서 바로 이용할 수 있게 동적으로 카드 목록이 갱신됩니다. 상세한 방법은 `recipe-guide/handoff.md`의 **유지보수 및 확장 가이드**를 참조하세요.
