# Recipe Guide (시각적 작업 지원 모듈)

**Recipe Guide**는 성인 지적장애인이 혼자서 또는 업무를 분담하여 다양한 카페 음료(예: 에어로프레스 아이스커피)를 만들 수 있도록 돕기 위해 개발된 **반응형 시각적 작업 지원 웹 애플리케이션**입니다. 

기존 진행 중인 "배달왔삼" 웹앱 등 다른 프로젝트에 쉽게 모듈(플러그인) 형태로 삽입될 수 있도록 설계되었습니다.

## ✨ 주요 기능 (Features)
- **모듈화 및 독립성**: 빌드 도구나 무거운 프레임워크(React, Vue 등) 없이 **순수 HTML, CSS, Vanilla JS**로만 작성되어 어디든 쉽게 이식 가능합니다.
- **모바일 우선(Mobile-First) 반응형 디자인**: 스마트폰, 태블릿, 데스크탑 등 어떤 환경에서도 명확하고 큼직한 UI를 제공합니다.
- **인지적 접근성 최적화**:
  - 한 화면에 하나의 지시사항만 배치하여 인지적 부담 최소화
  - "저어주기"와 "기다리기" 등 서로 다른 행동을 명확히 단계별로 분리
- **자동 음성 안내 (TTS 지원)**: 
  - 상단의 '음성 켜기' 버튼을 누르면, 단계가 넘어갈 때마다 지시사항을 친절한 음성으로 자동 안내합니다.
- **안전장치가 포함된 시각적 타이머**: 
  - 타이머가 필요한 단계(예: 60초 기다리기)에서는 타이머가 0이 되기 전까지 다음 단계로 넘어갈 수 없도록 버튼을 잠금 처리하여 실수를 방지합니다.

## 📂 프로젝트 구조 (Directory Structure)

```text
/
├── recipe-guide/
│   ├── index.html            # 진입점 및 기본 레이아웃
│   ├── css/
│   │   └── recipe-guide.css  # 독립적으로 네임스페이스(#recipe-guide-app)가 적용된 스타일
│   ├── js/
│   │   ├── recipe-data.js    # 레시피 데이터 (단계, 이미지 경로, 음성 대본 등)
│   │   └── recipe-guide.js   # 앱의 핵심 비즈니스 로직 및 UI 렌더링
│   └── assets/
│       └── aeropress/        # 에어로프레스 단계별 일러스트 에셋
└── README.md
```

## 🚀 사용 및 배포 방법 (How to Run)

1. **로컬 환경 실행**: 별도의 백엔드나 서버 설치 없이 `recipe-guide/index.html` 파일을 더블클릭하여 웹 브라우저에서 바로 실행할 수 있습니다.
2. **웹 배포**: 정적 파일(HTML, CSS, JS)로만 이루어져 있으므로 **GitHub Pages**, Vercel, Netlify 등에 폴더를 올리는 것만으로 즉시 무료 배포가 가능합니다.
3. **기존 앱(배달왔삼)에 통합하기**: 
   - `css/recipe-guide.css`와 `js/` 안의 파일들을 기존 앱으로 복사합니다.
   - 기존 앱의 HTML에 `<div id="recipe-guide-app"></div>` 컨테이너를 생성합니다.
   - 스크립트(`recipe-guide.js`)를 모듈로 불러오면 해당 `div` 내부에 레시피 가이드가 자동으로 렌더링됩니다.

## 🛠 확장 방법 (Adding New Recipes)

새로운 음료(예: 말차 바닐라라떼)를 추가하려면 `js/recipe-data.js` 파일에 새로운 레시피 객체를 추가하고, 해당 레시피의 ID를 `recipe-guide.js` 초기화 로직에 넘겨주기만 하면 됩니다.

```javascript
// 예시: recipe-data.js 에 추가
const RECIPE_DATA = {
  aeropress: { ... },
  matchaLatte: {
    id: "matchaLatte",
    title: "말차 바닐라라떼",
    steps: [ /* 단계별 데이터 */ ]
  }
};
```
