# TTS 작성 가이드

이 문서는 새 레시피를 추가하거나 기존 레시피 문구를 다듬을 때 사용하는 TTS 작성 기준입니다. 앱의 기본 원칙은 **화면 문구는 짧게, 음성 안내는 자세하게**입니다.

## 1. 화면 문구와 TTS를 분리하기

- `title`: 지금 할 일을 짧은 제목으로 씁니다.
- `instruction`: 화면에 보이는 짧은 행동 문구를 씁니다.
- `speech`: TTS가 읽을 자세한 안내 문장을 씁니다.

```javascript
{
  title: "뜨거운 물 넣기",
  instruction: ["뜨거운 물 80mL"],
  speech: "뜨거운 물 80밀리리터를 넣어요. 뜨거우니 천천히 기준선까지 부어요."
}
```

## 2. 화면 문구는 짧고 눈에 잘 들어오게 쓰기

화면 문구는 사용자가 사진을 보며 바로 행동을 떠올릴 수 있을 정도로만 씁니다.

- 좋은 예: `스틱 2개 준비`, `분말 모두 넣기`, `찬물 기준선까지`
- 피할 예: `말차 바닐라라떼 스틱 두 개를 준비하고 개수가 맞는지 확인해요.`

## 3. TTS는 기호와 단위를 풀어서 쓰기

TTS 문자열에는 기호를 그대로 넣지 않습니다. 음성이 어색하게 읽히거나 의미가 흐려질 수 있습니다.

| 화면 문구 | TTS 문구 |
| --- | --- |
| `80mL` | `80밀리리터` |
| `20g` | `20그램` |
| `2~3번` | `2번에서 3번` |
| `스틱 x2` | `스틱 2개` |

## 4. 행동 순서대로 한 문장씩 안내하기

TTS는 실제 손동작 순서대로 씁니다. 한 문장에 너무 많은 행동을 넣지 않습니다.

```text
절취선을 찾아 천천히 뜯어요. 스틱 2개를 모두 뜯어요.
```

```text
한 손으로 컵을 잡아요. 다른 손으로 뚜껑을 맞추고 가장자리를 눌러 닫아요. 뚜껑이 잘 닫혔는지 확인해요.
```

## 5. 안전이 필요한 단계는 TTS에 반드시 넣기

뜨거운 물, 날카로운 절취선, 뚜껑을 강하게 누르는 동작처럼 실수 가능성이 있는 단계는 화면보다 TTS에서 더 분명히 안내합니다.

```text
뜨거운 물 80밀리리터를 넣어요. 뜨거우니 천천히 기준선까지 부어요.
```

## 6. 말투는 일정하게 유지하기

- 기본 말투는 `~해요`, `~넣어요`, `~확인해요`를 사용합니다.
- 지시가 강해야 할 때만 `~해주세요`를 사용합니다.
- 한 단계 안에서는 같은 호칭과 단어를 반복해서 사용합니다.

## 7. 새 레시피 작성 체크리스트

- [ ] `instruction`은 한 줄 또는 두 줄의 짧은 화면 문구인가?
- [ ] `speech`는 화면 문구보다 자세하고 행동 순서가 분명한가?
- [ ] `mL`, `g`, `~`, `x2` 같은 기호를 TTS에서 풀어 썼는가?
- [ ] 뜨거운 물, 뚜껑, 찢기 같은 안전 요소를 TTS에 넣었는가?
- [ ] 다른 레시피와 말투가 비슷한가?
